# graficos-referencia

Referência de visualizações com Matplotlib/Seaborn e Streamlit/Plotly, mais **9 gráficos gerados a partir de datasets** (um script por gráfico).

- 📘 [Cheat sheet dos gráficos gerados](cheat_sheet_graficos_dados.md)
- 📘 [Matplotlib & Seaborn](matplotlib_e_seaborn.md) · [Parâmetros](parametros_graficos.md) · [Dashboards](dashboards_streamlit_plotly.md)

## Estrutura
```
dados/      CSVs de entrada
scripts/    um script por gráfico
graficos/   imagens PNG geradas
```

## Uso
```bash
pip install -r requirements.txt
python scripts/grafico_heatmap.py
```
